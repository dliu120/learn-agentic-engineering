# ALLM Academy

An immersive, **self-updating** static course on **production-LLM engineering** for AI engineers —
the systems work *around* the model. The curriculum uses 4 progressively disclosed layers:

**Published site:** https://dliu120.github.io/learn-agentic-engineering/

- **Fundamentals:** model calls, context windows, retrieval, state, memory, tools, and agents
- **Core Stages:** prompt → conversation → response → loop → graph engineering
- **Agent Capabilities:** skills/plugins/MCP, state/memory/durability, and executable specifications
- **Production Deep Dives:** inference, model efficiency, retrieval, evaluation, safety/cost, and strategy

The 15 modules start with 4 concise fundamentals lessons, then cover 32 focused topics with accessible 2D
diagrams, worked examples, one-question-at-a-time quizzes, resume points, local progress tracking, primary
references, and optional build-time audio narration.

A daily CI job curates AI news (Hacker News, arXiv, keyless GitHub Search, OpenAI/HF/blog RSS) into short teachable
briefings mapped back to the curriculum, so the site stays current without a runtime backend.

> Tech: Astro 7 (static) · Preact islands · Tailwind · SVG/Canvas teaching viz ·
> Pagefind search · edge-tts audio.

## Quick start

This repo uses [mise](https://mise.jdx.dev/) to manage the toolchain (Bun) and
[Bun](https://bun.sh/) as the package manager/runtime.

```bash
mise install           # install the toolchain pinned in mise.toml (latest Bun)
bun install            # install dependencies
bun run dev            # http://localhost:4321
bun run build          # static output in dist/ (astro build + pagefind index)
bun run preview        # serve the production build
```

## Scripts

| script | what it does |
|---|---|

| `bun run check:coverage` | assert all 32 topics are covered by lessons |
| `bun run check:daily-continuity` | validate every daily entry and fail on date gaps |
| `bun run daily` | run the daily pipeline → writes `src/content/daily/<date>.json` |
| `bun run daily:dry` | fetch + curate to `.tmp/` with no site changes |
| `bun run daily -- --date=YYYY-MM-DD --historical-backfill` | write a provenance-safe marker for a missing historical day without fetching live feeds |
| `bun run gen:audio` | edge-tts core-concept narration (no-op if edge-tts absent) |
| `bun run test` | Vitest unit tests |

### Design decisions
- **Static only.** No runtime server. The daily feed is regenerated by CI and committed.
- **Reduced-motion first.** Every viz renders a correct static final state and exposes a text
  equivalent; nothing depends on motion.
- **Progressive disclosure.** Fundamentals establish shared vocabulary, the 5-stage core stays visible,
  and capability/production paths open on demand. Lessons separate the main mental model from optional
  deep dives and references.
- **Progress is local.** `localStorage` only — export/import on the About page. No accounts, no tracking.
- **Quiz answer encoding:** mcq `correct:number`, multi/ordering `correct:number[]`, matching uses
  `pairs[]` as the canonical mapping (no `correct`).

## The daily pipeline

`bun run daily` fetches public feeds (see `sources.yaml`), dedupes/filters/ranks by relevance +
recency, then curates the top items into lessons mapped to the curriculum:

- GitHub discovery uses four cached Search API queries, one result per category, and a recent-`pushed_at` window.
  Stars/forks are labeled discovery signals, not evidence of quality or effectiveness.
- Generated lessons retain the exact candidate URL plus source type and available publication/activity time;
  model-written links that do not match a fetched candidate are rejected.

- **With** `ANTHROPIC_API_KEY` → LLM curation (summary + why-it-matters + micro-quiz), validated by
  Zod with a bounded repair loop. Flag: `curated`.
- **Without** a key → deterministic templated summaries. Flag: `uncurated-fallback`.
- **No candidates** clear the bar → a `quiet-day` evergreen card.
- **Historical gap without a retained source snapshot** → an explicit `historical-backfill` marker; live stories are never relabeled as past news.

All failure paths are graceful (a dead feed, bad LLM output, or missing edge-tts never crashes the
run). Copy `.env.example` → `.env` to configure.

### Honest limits
- Lesson numbers/prices/benchmarks are illustrative ranges — verify against primary sources.
- Reddit often returns 403 to automated requests and is skipped; Anthropic has no stable public RSS
  (proxied via Google News). X/Twitter has no keyless feed and is intentionally omitted.

## Deploy

Two GitHub Actions workflows are included:

- **`.github/workflows/deploy.yml`** — builds and deploys to **GitHub Pages** on push to `main`
  (needs only `GITHUB_TOKEN`). For a project site set `SITE`/`BASE` (see the workflow + `.env.example`).
- **`.github/workflows/daily.yml`** — cron job that runs the pipeline, commits the new day, and
  triggers a redeploy. Add `ANTHROPIC_API_KEY` as an Actions secret to enable LLM curation.

Any static host works (Netlify/Vercel-static/Cloudflare Pages) — just serve `dist/`.
